# 项目：星回 · Xing Hui-note

## 项目定位
- 自用字卡传讯网站，参考 Mochi 字卡传讯、milk 字卡。
- 用户与虚拟角色“星回”模拟聊天，回复从字卡库中随机抽取。
- 纯前端，单机应用，数据存 localStorage。
- 不需要后端、数据库、SEO、作品集页面。
- 账号系统先预留，不实现。

## 技术栈
- Vite + 原生 JS。
- 纯 HTML/CSS/JS，不使用 React/Vue。
- 所有数据存 localStorage，禁止 fetch 外部 API。
- 禁止后端、数据库、登录系统（预留按钮除外）。

## 设计规范
- 风格：现代极简、有呼吸感，不要默认 AI 味模板。
- 主色：夜空蓝 #1E3A5F。
- 辅助色：白色、银色。
- 点缀：很淡的星点微光，不花哨。
- 标题字体：Inter。正文：系统默认。
- 正文最大宽度 720px，整体居中。
- 间距基准 8px，区块间距 24/32/48。
- 消息气泡圆角 16px，按钮圆角 8px。
- 手机端单列，电脑端居中。
- 消息气泡：用户消息靠右，角色消息靠左。
- 输入框固定在底部，不遮挡消息列表。

## 视图结构
1. **首页**：上半部分大时钟（时间、日期、问候），下半部分图标+文字网格，排列各板块入口。
2. **聊天界面**：与星回对话。
3. **管理页**：字卡管理、表情包管理、拍一拍管理。
4. **收藏**：我收藏的 + 梦角收藏的。
5. **设置**：账号（预留）、聊天设置、头像上传、外观。
6. **数据备份**：导出全部、导入、自动备份提醒。
7. **拍一拍**：长按头像触发，单独字卡库。

不做：心情记录、互动版块（摸摸/抱抱、猜拳/掷骰子、纪念日）。

## 底部导航规则
- 只在 **首页、管理页、设置页** 显示。
- 从左到右：首页 / 管理 / 设置。
- 进入其他页面（聊天、收藏、数据备份、拍一拍）后，底部导航消失，只保留左上角返回箭头回首页。

## 数据模型（localStorage）
- 角色配置：{ name: "星回", avatar: "base64或默认图" }
- 分组：{ id, name }
- 字卡：{ id, groupId, content, disabled: false }
- 表情包：{ id, image: "base64", enabled: true }
- 拍一拍字卡：{ id, content }
- 聊天记录：{ id, role: "user"|"star", content, type: "text"|"sticker", timestamp, read: false, favorited: false, starFavorited: false }
- 收藏：从聊天记录中筛选 favorited 或 starFavorited
- 设置：{ replyDelayMin, replyDelayMax, typingIndicator, readNoReply, theme, showTimestamp, fontSize, darkMode }
- 当前选中分组 ID

## 核心逻辑
### 聊天
- 用户发送消息后，消息立即上屏，存入聊天记录。
- 从当前选中分组的字卡库中随机抽取一条，模拟延迟后作为星回回复。
- 延迟为范围随机，默认 1–3 秒，可调 0–600 秒。
- 如果当前分组无可用字卡，显示兜底回复“嗯嗯”。
- 星回回复时显示“对方正在输入…”。
- “已读不回”开启时，有概率不回复，只标记已读。
- 星回每次回复有 5% 概率被标记为“梦角收藏”。

### 消息操作
- 点击消息，上方浮出一行小字：删除、撤回、收藏。
- **删除**：任何消息都能删，彻底移除。
- **撤回**：只针对我发的消息，撤回后消失或显示“你撤回了一条消息”。
- **收藏**：收藏该消息。
- 时间戳显示在消息下方，小字，只有时分（如 14:32），不含年月日。
- 我发的消息，时间旁边显示“已读”。

### 字卡管理
- 字卡包含：内容、分组、禁用/启用。
- 分组可自建、可修改、可删除。
- 禁用的字卡不参与随机抽取，但保留在库里。
- 支持多选，批量操作：批量禁用/启用、批量删除、批量移动到分组。
- 去重：全库扫描，内容完全一致只留一条。
- 一键导入：从 JSON 文件导入，导入前先选目标分组。
- 自行导入：手动输入或粘贴文本，每行一张字卡，导入前先选目标分组。
- 导出：可多选，自行勾选要导出的数据。

### 表情包管理
- 用户能发，星回也能随机回。
- 只支持本地上传图片，存到浏览器。
- 星回回复时可能随机抽到表情包。

### 拍一拍
- 长按星回头像触发。
- 显示“你拍了拍星回”。
- 星回有概率回一句，有概率不回。
- 拍一拍字卡库在管理页里单独一栏。

### 收藏
- 两栏：“我收藏的”和“梦角收藏的”。
- 我收藏的：我点收藏的消息。
- 梦角收藏的：星回回复时随机概率标记的消息。

### 设置
- 账号：登录/注册按钮（预留，不实现）。
- 聊天设置：回复延迟范围（最小/最大秒数，0–600，默认 1–3）、正在输入开关、已读不回开关。
- 头像：星回头像可上传本地图片。
- 外观：主题色（深蓝、白银、浅蓝三套预设）、时间戳开关、字体大小、深浅模式。

### 数据备份
- 导出全部数据：字卡、表情包、聊天记录、收藏、设置，打包成 JSON 下载。
- 导入数据：选择之前导出的 JSON 文件恢复。
- 自动备份提醒：超过 7 天没导出，首页显示提醒。
- 不做“清空所有数据”。

## 安全与合规
- 页脚免责声明：“字卡回复均为随机代码生成，不具备任何真实效力。使用本站产生的一切后果由使用者自行承担。”
- 手机端提示：建议使用 Chrome 或 Edge 浏览器。
- 自用也建议保留年龄提示或防沉迷说明。

## 代码协作规则
- 每次只改指定区块，不要重写全站。
- 只输出修改后的文件或相关片段，不要重复输出整个文件。
- 改逻辑前先说明方案，确认后再写代码。
- 不要动无关视图、无关文件。
- 新增功能必须说明验收标准。

## 禁止事项
- 禁止后端 API、数据库、登录（预留按钮除外）。
- 禁止默认 AI 模板风格。
- 禁止自动播放声音、视频。
- 禁止收集任何用户数据。
- 禁止把字卡数据写死在代码里（系统内置兜底除外）。

## 账号与云同步（可选层）
- 默认行为：纯本地模式，使用 localStorage，无需登录。
- 增强行为：用户可选择性登录，登录后数据同步到云端。
- 云服务选型：Supabase（推荐）或 Firebase。
- 认证方式：手机号+密码，或 GitHub/Google OAuth。
- 同步策略：本地优先（local-first），登录时合并本地与云端数据。
- 安全原则：依靠行级安全（RLS）策略保护数据，而非依赖密钥保密。
- 降级兼容：未登录、无网络、或云服务未配置时，网站必须完全可用。
